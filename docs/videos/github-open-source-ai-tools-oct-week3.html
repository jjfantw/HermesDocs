影片官方說明（原文）
1｜magpie：一个本地模型网关，把你所有编程助手的模型和订阅收到一处。菜单栏点一下就换模型，Claude Code、Codex、Gemini CLI、OpenCode 都能共用同一批 key 和订阅；按 smart、order、rotate、usage、pace 等策略在成员间分发请求，某个配额用完会自动换下一个。README 还提到能从 CC Switch 导入已有供应商配置。链接：https://github.com/yetone/magpie

2｜ArtCraft：艺术家的 AI 创作 IDE。先在二维画布合成、再到三维里摆好场景道具和相机，然后才交给模型生成，做可控可复现的图片和视频；内置 62 个模型目录，覆盖图像、视频、音乐音效和三维，像 Nano Banana、FLUX、可灵、Veo 都在里面。链接：https://github.com/storytold/artcraft

3｜ai-memory：给编程助手的跨工具长期记忆。在 Claude Code 干到一半退出，去 Codex 的同一个目录接着干，不用重讲架构和试过的失败路；记忆就是一堆 git 管的 markdown 文件，能直接 grep、用 Obsidian 打开，数据库只是能随时重建的索引，默认全程零大模型调用。链接：https://github.com/akitaonrails/ai-memory

4｜Filee：拖拽式离线文件转换器。按住键拖动文件，光标处弹出一个甜甜圈选目标格式，只显示能转的格式，支持 255 种格式、离线转换、结果存原文件旁边；多步转换路线会自己找出来，从 Releases 下载即用，Windows、macOS、Linux 都有。链接：https://github.com/KnifeLemon/Filee

5｜Strata：在自己的游戏 PC 上跑大模型。按项目自述可在普通游戏显卡上跑一个大参数模型，兼容 OpenAI 和 Anthropic 接口，能接别的应用，聊天和文件都留在本机；三种装法：下载桌面应用、一行命令，或者让 AI 助手照仓库说明自己装。链接：https://github.com/Niko1221/Strata
