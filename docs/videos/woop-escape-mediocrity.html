2. WOOP 是把願望接上阻礙與行動的工具

00:34

影片提出 WOOP 作為擺脫平庸的工具。W 是 Wish：具體想達到什麼目標；第一個 O 是 Outcome：目標達成後會有什麼好結果，並且要盡量想像那個畫面。

第二個 O 是 Obstacle：阻礙你達成目標的障礙到底是什麼；P 是 Plan：當障礙出現後，你要採取什麼行動。影片特別強調，一個具體可以執行的行動就好了。

3. 減重例子：把目標、結果、障礙、計畫拆清楚

01:03

影片用減重示範 WOOP。Wish 是五週內瘦五公斤；Outcome 是兩個月後員工旅遊時，在海邊拍出好看的照片，身體也變得比較健康。

Obstacle 是下班回家後躺在沙發上覺得累、懶得出去健身。Plan 則是下班後根本不要先回家，直接帶鞋子和衣服去健身房，把阻礙運動的障礙排除。

4. WOOP 與顯化的差異：不只想像，也處理執行

01:39

影片說明，顯化通常是先設定明確目標，再一直想像自己已經得到那件東西後的美好。問題是，如果大腦已經覺得自己得到，就可能放棄努力。

另外，如果想像很美好，但行動沒有跟上，中間的落差會讓人痛苦，甚至覺得是自己顯化得不夠好。講者認為，WOOP 很好地彌補了顯化在執行上的不足。

顯化 vs WOOP

WOOP 的重點不是只想像美好結果，而是把阻礙和下一步行動一起放進計畫裡。
