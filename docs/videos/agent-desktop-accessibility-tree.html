影片將 agent-desktop 的基礎描述為作業系統內建的「畫面說明書」：無障礙樹原先用來讓螢幕閱讀器知道每個按鈕的名稱與可否操作。

工具把這份結構轉成 AI 可讀的清單，並為元素編號；AI 依序讀取、執行指定編號、再讀取確認。
