EP697 我每天都在吸收新知，卻好像都沒有長進？你可能少了學習中最重要的「下一步」｜大人的Small Talk

📺 大人學⏱ 22:23🗓 2026-08-13🌐 zh-Hant🔗 https://www.youtube.com/watch?v=oXhQWt5m4GY

這集從『每天吸收很多新知卻沒有長進』的焦慮出發，區分兩種努力：低風險、讓人感覺正在前進的輸入型努力，以及需要做決定、交付成果、承擔回饋的輸出型努力。Joe 指出，買課、看書、收藏文章本身有價值，但若長期停在輸入端，容易形成以學習壓制焦慮、卻不改變現實的循環。節目也把中年人遇到職涯瓶頸時『逃回學校』放進同一個框架：問題不一定是缺技能，而可能是缺少定位、選擇、承擔與冒險。最後提供一個自我檢查方法：回看過去一個月的行事曆或待辦清單，標記每件努力是輸入還是輸出，若嚴重失衡，就刻意增加小型輸出，讓學習重新回到真實世界的回饋循環。

01

1. 資訊上的忙碌，不等於人生有前進

1:40

Joe 先描述一種常見狀態：手機裡有線上課程，通勤聽 Podcast，吃飯看知識影片，週末去上課，書架上堆著還沒拆封的書，筆記軟體也收藏了大量文章與工具。

這些行為表面上很積極，當事人也會覺得自己一直在學習；但節目追問的是：這些輸入是否真的改變生活、增加職場競爭力，或讓日子更踏實、不焦慮？

知識焦慮
02

2. 輸入型努力提供安全的進步感

4:19

節目把買課、看書、整理筆記、收集資訊稱為輸入型努力。這些事情重要，但共同特徵是風險低：上課不太會失敗，看書不會讓人生崩盤，收藏文章也不需要承擔後果。

因此，輸入會讓人產生『我正在往前走』的感覺，卻不一定迫使人面對真實世界的檢驗。它提供的是安全的進步感，而不是完整的成長。

輸入型努力
03

3. 輸出型努力必須下注、交付、面對回饋

5:49

Joe 把另一種努力稱為輸出型努力：真的做決定、做一件事、交付作品，並承擔清楚責任。它要求你為自己的選擇下注，面對市場、客戶、老闆或他人的真實回饋。

節目舉了幾個例子：學專案管理只是輸入，真的帶專案、協調團隊甚至搞砸後被罵，才是輸出；看寫作書是輸入，把文章發表出去、接受好壞評價，才是輸出；看溝通書是輸入，去找難相處的同事談一場困難對話，才是輸出。

輸出型努力
04

4. 只輸入不輸出，會把焦慮包裝成努力

8:28

節目指出，有些人不是不努力，而是努力長期留在輸入端。輸入端舒服、安全，還會帶來『我有努力』的自我感覺良好，因此成為一個努力的避風港。

問題是，對未來焦慮所以去學習，學習得到短暫安全感；但因為沒有輸出，現實處境沒有改變，焦慮就繼續存在。於是人又投入更多課程與書籍，試圖壓制焦慮，卻沒有打破循環。

努力的避風港
05

5. 回學校有時是成長，有時是逃回學生模式

11:28

Joe 延伸到中年職涯困境：有些人升不上去，不一定是缺一個技能，而是面臨定位、選擇、承擔與冒險。例如要不要爭取部門經理、創業、換公司，或接下燙手山芋的專案。

在這種焦慮下，回學校會很有吸引力，因為學校提供熟悉、安全、有課表、有作業、有考試、有分數的框架。節目提醒：回學校不一定是壞事，但要誠實問自己，這是輸出型的成長策略，還是逃離自己不想決定下一步的巨大焦慮。

中年職涯
06

6. 用一個月清單檢查輸入與輸出比例

16:24

Joe 提供的具體方法很簡單：打開行事曆或待辦清單，回看過去一個月你覺得自己很努力的事情，逐項標記它是輸入還是輸出。

看完一本書、買書、整理會議紀錄、找朋友請教人生難題，多半仍是輸入；根據書寫心得並發表、把上課方法改造進工作流程、整理會議紀錄後提出三個下一步並找主管溝通、聽完朋友建議後真的執行並回頭討論，才是輸出。

自我檢查
07

7. 成長來自輸入與輸出的循環

18:33

節目沒有否定輸入，而是強調平衡。健康的成長狀態，是輸入和輸出不斷循環：看了書就拿來用，上了課就把工具帶進職場，遇到新問題再回來取得新的輸入。

當你開始插入小小的輸出，例如寫文章、發表觀點、向老闆爭取小任務，或執行拖延已久的小決定，你會取得更多真實訊息，知道下一步還需要什麼輸入。這也是焦慮下降的起點。

行動循環

學習要真的跟世界產生碰撞，創造真實的改變；不是只學、只買書、只買課，而是掌握方向、了解問題、取得輸入，然後去做些什麼。
