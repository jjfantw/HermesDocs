I Have ADHD 是什麼？

00:00

「I Have ADHD」是一個近期在開發者社群爆紅的開源 Claude Code Skill，GitHub 連結：https://github.com/ayghri/i-have-adhd。

它的核心概念非常簡單：AI 回答時常常前面講一大堆，最後才告訴你真正該做什麼。裝了這個 Skill 之後，AI 的回答變得更直接、更好讀，也更容易照著做。

在 X（Twitter）上，有一位開源大佬直接說：裝完之後輸出品質提升了 10 倍。

02

三條核心輸出規則

00:23

規則一：先講下一步，不要先鋪陳背景。 不要先說一堆分析，一開頭就告訴你現在該做什麼。

規則二：多步驟任務要編號。 只要超過一個步驟，就拆成 1、2、3，每一步都要是明確可以執行的動作。

規則三：避免離題。 如果還有第二個問題，不要全部混在一起講。先把眼前這件事處理完，再問你要不要處理下一件。

核心規則
03

為什麼值得裝？

00:43

簡單講，它不是讓 AI 變聰明，而是讓 AI 不要把答案藏在一堆廢話裡。

如果你覺得 AI Agent 常常講太多、重點太慢出現，這個 Skill 很值得裝來試試看。

結論
