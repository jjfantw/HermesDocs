01

NotebookLM → Gemini Notebook：改名背後的三項重大更新

0:00

Google 在 2026 年 7 月 16 日正式宣布將 NotebookLM 改名為 Gemini Notebook，納入 Gemini 產品家族。這款產品最初是 Google 內部的 20% 創業項目，2023 年上線後因巧妙結合 Google 生態數據與 Gemini AI 引擎而大獲好評。

改名不只是換名字，同步帶來三項更新：第一，多模態輸出能力再進化——原本就能輸出音頻、幻燈片、文字、圖像，現在新增短視頻和數百萬視頻輸出，加上 PDF、Excel、圖表、報告等格式，覆蓋通勤聽音頻、匯報用幻燈片、演示用視頻、深入理解用思維導圖等場景。

第二，深度研究功能——啟動調研時不再需要使用者費心提供初始材料，只需簡單描述需求，Gemini Notebook 就會自動搜尋網路資料作為啟動資訊，大幅降低使用門檻。

第三，每個筆記本配一台雲電腦——使用者可以在雲端原生撰寫和執行腳本，進行深度分析。此功能已開放給 Eldra 方案和 Google Workspace Business 使用者，Pro 方案將在接下來幾週開放。

02

實戰示範：用 Gemini Notebook 做「購買電動車調研」

3:04

影片以「選購最適合家庭的電動車」為實例，展示完整流程：

步驟 1：建立新筆記本，直接輸入需求描述（例如「我想把家裡的車換成電動車，請幫我調研推薦車型」），選擇資料來源（網路或 Google Drive），再選擇快速搜尋或深度分析。

步驟 2：自動調研——Gemini Notebook 會在背景自動搜尋、匯總資料，即使關掉頁面也沒關係。完成後點擊 Import 即可將所有資料導入筆記本。

步驟 3：互動提問——導入後主界面會顯示內容摘要和建議問題。可以直接提問（例如「如何選擇電動車？給我選購標準」），Notebook 會從已收錄的資料中分析並回答。回答還可以 Save to Note → Convert to Source，變成新的資訊源加入調研。

步驟 4：加入個人化資料——透過 Add Sources → Copy Text，貼上自己的家庭情況（預算、人數、用途等），讓推薦更精準。再次提問「根據我的需求推薦車型、分析優缺點、放入表格」，Notebook 會結合所有資料給出個人化建議。

04

資料管理與多樣化輸出格式

5:44

資料來源支援上傳文件、網頁連結（含 YouTube）、Google Drive、貼上文字，格式涵蓋 PDF、圖片、Google Doc、音頻等。左側資料列表可一鍵切換「標籤視圖」，由模型自動將資料分類並以標籤聚合顯示。

輸出格式（Studio 列表）包括：音頻、長視頻、短視頻、幻燈片、思維導圖、報告、閃卡、問答題、資訊圖譜、數據報告。重要提示：不要直接點擊按鈕（會用預設設定生成），應點擊右箭頭進入自訂設定。

視頻生成有三種風格可選：電影級（高畫質）、平鋪直敘（簡潔重點）、短視頻（豎向格式）。目前視頻僅支援英文，音頻和幻燈片可選語言。生成時間約 10 分鐘，完成後手機 APP 會通知。

影片作者個人最常用的是音頻（通勤時快速了解內容）和資訊圖譜（高效掌握全景）。

MCP 對接：讓本地 AI Agent 操控 Gemini Notebook

13:05

Gemini Notebook 目前不能原生融入 Agent 工作流，但社群開發了 NotebookLM MCP 伺服器（GitHub: PleasePrompto/notebooklm-mcp），讓本地 Agent 可以與 Gemini Notebook 互動。

支援功能：上傳檔案到特定筆記本、生成並下載音頻、管理筆記本內容。應用場景包括：將 Obsidian 筆記同步到線上 Notebook、利用 Notebook 能力進行話題研究並產出多模態內容、自動製作播客等。

配置方式：支援 Claude Code、Cursor、Codex 等 MCP 相容 Agent。最簡單的做法是直接把 GitHub 連結丟給 Agent，說「Please config MCP for me」，約 10-15 分鐘自動完成配置。

MCP 原理：在本地啟動 headless browser 訪問 Gemini Notebook 頁面進行操作。首次使用需人工授權產生 cookie，之後全自動。使用前需先建立筆記本、設定「Anyone with a link」分享權限、將連結註冊到 Agent。

06

MCP 的現狀限制與使用建議

17:04

目前問題：Gemini Notebook 改名後前端 CSS/JS 程式碼有變更，而 MCP 伺服器是三個月前更新的，部分網頁元素選取會失效。有 fallback 機制——MCP 會自動打開可見瀏覽器頁面進行操作，或由 Agent（如 Codex）用自己的瀏覽器功能手動完成。

使用建議：MCP 啟動依賴瀏覽器，前後端操作較花時間。如果只是提問或上傳一兩條資料，性價比不高。最適合融入較重的自動化流程，例如批次處理多個調研任務或定時產出內容。

由於不是 Google 官方 MCP，功能穩定性受 Notebook 前端改版影響較大，需關注後續更新。

MCP 限制

Gemini Notebook 能把所有內容匯總後以不同形式輸出，讓你在不同場景快速掌握知識體系——通勤聽音頻、匯報用幻燈片、演示用視頻、深入理解用思維導圖。搭配 MCP 整合到自動化工作流，更能大幅提升調研效率。
