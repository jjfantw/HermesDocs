極客流 Mac 生產力工作流：效率、文本、媒體工具配置

📺 安枫的叶⏱ 8:54🗓 2025-12-03🌐 zh-Hans🔗 https://www.youtube.com/watch?v=JT2-lkfSMWs

這支影片分享一套作者主觀推薦的 Mac 生產力軟體組合，分成三個面向：效率工具用來縮短啟動、搜尋、剪貼與視窗管理流程；文本工具用來降低格式調整與程式碼瀏覽的摩擦；媒體工具則服務影片剪輯、投屏與錄屏，讓獨立創作者用較低門檻完成輸出。作者不主張用單一 All-in-one 外掛取代所有小功能，而是偏好互動一致、各司其職的獨立 App。

01

效率層：用 Alfred 把搜尋與啟動壓成一步

00:43

作者把 Alfred 視為 macOS Spotlight 的強化版，用 `Command + Space` 呼出後，可以快速開啟應用、用空格加檔名定位檔案，也能用符號喚醒命令列。

真正的重點是自訂網路搜尋：把常用搜尋結果頁的 URL 複製進 Alfred Web Search，將關鍵字部分替換成 query，再配置縮寫。作者舉例把 B 站、YouTube、PyTorch 手冊映射成簡短關鍵字，讓「開瀏覽器、輸入地址、搜尋」變成一次輸入。

效率
02

剪貼層：Paste 把複製過的素材變成可管理資料庫

01:43

Paste 的角色不是單純剪貼簿歷史，而是把文字、程式碼、圖片、音訊檔、簡報等複製內容用時間軸可視化保存。作者使用 `Command + Shift + V` 從螢幕底部呼出歷史。

作者也用 Pinboard 建立素材分類，例如常用 AI 提示詞、Markdown 協作時常用的 HTML 程式碼；需要時直接呼出，不必重複輸入。相比 Alfred 內建剪貼簿，作者更偏好 Paste 的 UI、媒體流轉與拖曳成實體檔案的直覺體驗。

效率
03

視窗層：Wins 管理分屏、切換與專注

02:40

Wins 的基本功能是視窗邊緣吸附與快捷鍵歸位，例如作者把 `Option + Shift + 5` 設成視窗置中。

作者最喜歡的是 Wins 重構了 `Command + Tab` 應用切換器：原生 macOS 只顯示圖示，Wins 會給出即時視窗預覽，多個瀏覽器視窗查資料時不用盲猜。

影片也提到類似 Shake Minimize 的專注功能：晃動目前視窗即可最小化其他應用。不過作者指出多螢幕情境有瑕疵，目前會最小化所有顯示器內容，他希望未來只清理當前螢幕。

效率
04

文本層：Typora + Paste，把格式勞動交給符號與片段

03:41

ASR 聽成 Typer，但上下文指向 Typora。作者看重的是「輸入即渲染」：用 Markdown 符號維持純文字的整潔，例如標題、黃色高亮等，輸入完成後立即渲染成格式化內容。

Typora 也支援嵌入 HTML，因此可以和 Paste 組合：先在 Paste Pinboard 預存紅色加粗等 HTML 片段，寫作時一鍵插入。作者認為這讓他從格式調整的機械工作中解放出來。

對工科使用者，影片還提到 LaTeX 公式與程式碼區塊高亮，適合技術文件與學術筆記。

文本
05

程式碼層：Sublime Text 作為輕量瀏覽器與臨時草稿紙

04:36

作者不把 Sublime Text 定位成像 VS Code 那樣的嚴肅開發環境，而是拿來快速瀏覽程式碼結構、修改設定檔，重點是原生級啟動速度與語法高亮。

影片示範多游標編輯：選中變數 `device`，用 `Command + D` 批量選中後改成 `sensor`，也可以搭配正則查找替換。

另一個重點是 Hot Exit：臨時貼上日誌或程式碼分析，用完直接 `Command + Q` 退出，不必保存檔案，下次打開仍會恢復。

文本
06

媒體層：FCP 負責架構，剪映負責快速收尾

05:35

作者的影片創作策略是以 Final Cut Pro 搭建整體結構，再用剪映做視覺包裝與細節潤飾。

Final Cut Pro 的優勢在於 macOS 原生速度、磁性時間線，以及處理人臉打碼或局部調色時可自動鎖定移動目標的物件追蹤／遮罩能力。

剪映則像開箱即用的效率工具，用來補足 FCP 在細節潤飾上的繁瑣，例如 AI 智慧字幕、貼紙與特效。作者強調，對獨立創作者來說，高效表達比炫技更重要。

媒體
07

投屏與錄屏：降低設備切換與畫面錄製摩擦

06:49

投屏段落的工具名 ASR 聽成 ScreenCopy，但作者提到 Homebrew 安裝與終端命令，語境應是 scrcpy。它讓 Mac + Android 使用者把手機投到 Mac，並由 Mac 鍵鼠接管，減少拿起手機造成的心流中斷。

錄屏段落的工具名 ASR 聽成 AllMe，需人工核對。影片提到它解決 macOS 無法錄製系統內部聲音的痛點，並支援多解析度、多幀率、畫中畫攝影機與只錄指定 App 視窗。
