AI 時代成為超級個體：從超級終端開始

📺 安楓的葉⏱ 14:28🗓 2026-05-23🌐 zh-Hans🔗 https://www.youtube.com/watch?v=soesYA1gNmo

這支影片示範作者的「超級終端」配置：在 AI Agent 時代，終端被視為駕馭 AI 與工具鏈的控制中樞。影片從四個維度拆解：視覺交互、導航搜尋、文件管理、開發工具；並提供 GitHub 倉庫，讓 AI Agent 協助一鍵部署。核心思路不是炫技，而是把 CLI、tmux、搜尋工具、檔案管理器與開發環境整合成可長時間使用、可恢復、可協作的工作站。

01

CLI 重新成為 AI Agent 的控制中樞

00:00

影片開場把 AI Agent 與命令列的結合稱為一場「文藝復興」：頂級模型正在回到純文字終端，因為大語言模型能以較原生的方式嵌入 CLI，並調度龐大的終端工具鏈。

作者的結論是：在 Agent 時代，終端不只是老派工程師的工具，而是駕馭 AI、管理工具鏈與執行任務的控制中樞。想把 AI 變成日常工作能力，第一步是配置一個強大、高效的終端環境。

核心觀點
02

整套超級終端被拆成六個工作區

00:49

作者展示的環境分成六個獨立工作區，透過 Alt + 數字鍵快速切換。核心主開發區採用四宮格布局，整合程式碼編輯、命令執行、版本控制與文件管理四個面板。

AI Agent 協作區採雙智能體並行：作者舉例偏好用 Codex CLI 專注程式碼實作，Gemini CLI 負責邏輯問答。其他工作區包含 SSH 遠端部署 / 模型訓練、log 檢查、btop 資源監控，以及 Manual 手冊區用來搜尋自訂快捷指令。

03

視覺交互：讓終端可長時間使用

02:10

視覺層以 Ghostty 作為終端模擬器，作者提到可用主題列表命令挑選皮膚，並用自訂別名快速切換主題。tmux 的面板放大 / 還原則透過 Ctrl + B → Z 完成。

Ghostty 之外，作者使用 Nerd Font 讓終端能顯示圖示，使用 zsh 語法高亮做防呆：有效命令顯示為綠色，無效命令顯示紅色。Starship 則提供雙行提示符與環境感知，讓第一行顯示上下文資訊，第二行保留輸入空間，降低長時間閱讀疲勞。

tmux 在此不只負責面板布局，也提供面板切換、放大、還原等空間操作；後面開發工具章節再延伸到 session 持久化。

04

導航搜尋：zoxide、fd、ripgrep、fzf 組成高速導航儀

03:46

zoxide 取代傳統 cd：它會記錄目錄存取頻率，依分數排序並支援模糊匹配。作者示範用簡短關鍵字快速跳到高頻專案，也把查詢分數的命令包成別名。

fd 用來取代 find，處理檔案查找；它支援副檔名篩選、正則、智慧大小寫，也會自動跳過隱藏檔與 .gitignore 內容。作者最常用的是按時間回溯近期改動檔案，並包成 fchange 之類的別名。

ripgrep 用來找內容，特別是 Markdown、程式碼與 TODO。作者強調 `-C` context 上下文輸出：搜尋命中時同時印出上下幾行，能判斷 TODO 所在業務邏輯。fzf 則把歷史命令、Git 分支等靜態輸出變成可互動選單。

05

文件管理：eza、bat、yazi 分別處理列表、預覽與全局管理

08:04

eza 被作者用來接管 ls 別名，提供資料夾優先、Nerd Font 圖示、Git 狀態與 hyperlink。影片也提到 Ghostty 與 tmux 同時使用時，滑鼠點擊檔案的組合鍵會不同：純 Ghostty 用 Command + 左鍵，開啟 tmux 後改用 Shift + Command + 左鍵。

bat 負責快速預覽檔案內容，提供類似 IDE 的語法高亮與行號，也能顯示 Git 狀態：修改、刪除、新增以不同符號呈現。

yazi 被用作沉浸式終端文件管理器。影片示範建立多個 C++ 檔案、用副檔名過濾、視覺模式批量選取、剪切並貼到 test 資料夾，也展示多標籤頁與圖片預覽。

06

開發工具：tmux session、lazygit、LazyVim 串成同一條工作流

11:01

tmux 真正核心的能力是 session 管理與後台托管。作者示範用自訂快捷啟動命令建立 workplace，預設集成六個 windows；即使終端關閉或 SSH 斷線，session 內的進程與狀態仍會保留，之後可重新 attach 恢復現場。

lazygit 接管 Git 操作：在 TUI 中切換 files、branches、commits、stash 等面板，對改動檔案用空格暫存或撤銷，按 C 填寫 commit 訊息，提交後再用大寫 P push。作者也提到 merge、rebase 這類複雜操作在可視化介面中更容易處理。

LazyVim 提供接近現代 IDE 的開發體驗。影片以 C++ / CMake 專案為例，說明 LazyVim 可讀取 CMakeLists.txt 並完成編譯與執行；同時可用 `Space gg` 在編輯環境中叫出 lazygit，讓編碼與版本控制在同一終端裡銜接。

作者最後提醒，影片中的 UI 與視覺配置帶有很強的個人審美偏好；如果使用者有自己的審美或工作流需求，可以把專案倉庫當作底座，自由修改成自己的終端外觀與操作方式。
