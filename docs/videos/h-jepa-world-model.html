H-JEPA 開源：楊立昆的分層世界模型與世界模型路線

📺 最佳拍檔⏱ 16:48🗓 2026-10-18🌐 zh-Hans🔗 https://youtu.be/6eHi1hGKw_k

影片整理 AMI 開源 H-JEPA 論文、程式碼與預訓練權重所提出的分層世界模型。其核心是讓不同層級在各自的潛在表徵空間與時間尺度做預測，規劃再由高至低展開成動作。在 Visual AntMaze 迷宮任務中，影片引述三層 H-JEPA 成功率為 73.3%，單層模型為 18.0%，且分層模型的規劃計算開銷更低。影片說明，收益可分開檢視：時間分解讓子目標的代價訊號更單調；較抽象的目標表徵空間也能改善目標距離的評分。影片同時呈現 DROID 真實機器人資料上的「慢特徵坍塌」問題及逆動力學損失的修補方式，並列出層數、訓練片段長度與真機閉環控制等尚未解決的限制。最後，影片把 H-JEPA 放進世界模型與 LLM 路線的討論，並比較 H-JEPA、World Labs Marble、DeepMind Genie 3 的不同取向。

01

分層的目的：各層處理不同時間尺度與抽象程度

01:00

影片以「規劃從紐約大學去巴黎」與「走下辦公室樓梯」對照：前者關心目的地、航班與時間安排，後者關心眼前地面與下一步。影片以此說明高層規劃和低層控制需要的資訊不同。

H-JEPA 要讓不同層級各自學得適合其時間尺度的表徵，並將高層計畫逐層落實為具體動作。

架構動機
02

H-JEPA 的架構與自上而下規劃

03:20

影片說明每層都有狀態編碼器、動作編碼器與預測器。底層直接讀取影像，較高層則處理下層潛在狀態；低層動作是具體動作，高層將連續動作壓縮為較粗粒度的變化。

規劃時，最高層先產生宏觀動作與中間狀態，這些狀態再作為下一層的子目標，直到第一層輸出可執行動作。閉環控制中，各層只匹配第一個預測子目標，執行一小段後重新觀測與規劃。

模型設計
03

模擬結果與兩種可分離的收益來源

05:40

在 Visual AntMaze 中，影片引述三層 H-JEPA 的成功率為 73.3%，單層扁平模型為 18.0%，且每回合規劃計算開銷更低。高層表徵會逐漸模糊快速變化的腿部姿態或干擾物，同時保留迷宮中的全局位置與對機器人本體的穩定感知。

影片介紹的消融實驗把分層收益拆成兩部分：時間分解把長程搜尋化為子目標；在較抽象的上層表徵空間衡量目標距離，單獨也能把迷宮成績從 18% 提升至 20.7% 至 31.3% 之間。

實驗結果
04

真實資料的慢特徵坍塌與修補

08:30

影片指出，在 DROID 的離線真實機器人資料中，場景與背景往往比機械臂動作更穩定。若模型只追求預測後續表徵與維持表徵差異，可能記住廚房、辦公室或工作臺，卻丟掉夾爪與動作等任務細節。

影片將此稱為慢特徵坍塌，並介紹以逆動力學損失要求模型由前後狀態反推中間動作，迫使其保留動作相關資訊。影片也提到，該約束需要帶有動作資訊的訓練資料。

真實機器人資料
05

限制與世界模型路線的定位

10:30

影片明確提出：層數並非愈多愈好；短回合資料可能無法供應高層所需的長片段；忽略難預測細節也可能忽略對任務成敗關鍵的短暫接觸。真機閉環控制仍是下一步計畫。

在較宏觀的比較中，影片將 H-JEPA 描述為在潛在空間進行抽象預測的路線；Marble 側重可編輯的結構化 3D 空間；Genie 3 則在像素空間預測並生成互動式 3D 環境。影片的結論是，這些路線從不同側面處理同一個世界模型目標。

限制與產業脈絡

影片將可下載、可復現、可繼續修改的實驗，視為比口號更具說服力的世界模型路線驗證。

重點時間戳索引

  1. 00:00影片介紹 AMI 開源 H-JEPA；在 Visual AntMaze 的 50 個任務評估中，三層模型成功率為 73.3%，單層扁平模型為 18.0%。
  2. 02:00單一潛在空間與單一時間尺度同時承擔低層動態建模和高層目標匹配，會造成長程誤差累積與目標衡量困難。
  3. 03:20H-JEPA 讓每層具有自己的狀態編碼器、動作編碼器與預測器；高層的一步對應低層兩步，並以端到端方式訓練。
  4. 07:00消融實驗指出，除了時間分解，改用更抽象的上層表徵空間衡量目標距離，單獨也能改善迷宮任務的表現。

  6. 10:30影片列出限制：層數不是越多越好；可預測性不必然等同任務重要性；真機閉環控制仍是後續工作。
