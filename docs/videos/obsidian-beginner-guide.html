零基礎 20 分鐘學會 Obsidian 95% 功能：從 Vault 到雙向連結的入門指南

📺 李廠長來了⏱ 18:03🗓 2026-08-08🌐 zh-Hant🔗 https://www.youtube.com/watch?v=NIhT5pd4Znc

這支影片用零基礎教學方式介紹 Obsidian：先指出許多人把資料分散在不同軟體裡，最後變成「知識囤積」而不是可重用的知識管理；接著說明第二大腦的概念，是把值得保留的資訊放進可靠的外部系統，日後能快速找回並看見知識間的連結。影片示範 Obsidian 的下載、安裝與建立 Vault，並強調 Vault 本質上是本機資料夾，筆記以 Markdown 保存，因此資料仍由使用者掌控，也能被其他程式讀取。後半段依序介紹主畫面按鍵、搜尋、書籤、快速切換、關係圖譜、白板、每日筆記、模板、命令面板與資料庫等功能。影片也示範附件資料夾設定、核心插件與第三方插件管理，以及 Markdown 標題、粗體、斜體、列表與任務勾選框。最後重點放在雙向連結、反向連結、嵌入筆記、外部連結與關係圖譜，並用「文件夾像建築物、連結像道路」的比喻說明：文件夾用來放需要固定位置的資料，連結才是整理概念關係的主要工具。

01

先解決「知識囤積」：資料要能被找回與再利用

00:00

影片開頭把問題定義得很清楚：很多人用手機筆記、Google Drive、Notion 等工具保存資料，但真正遇到工作或學習需求時，仍要回到大量文件夾裡搜尋與篩選。

講者把這種狀態稱為不是知識管理，而是知識囤積；Obsidian 要解決的是讓資訊能被長期累積、重新找回、並且在不同想法之間建立聯繫。

知識管理
02

第二大腦的核心：可靠外部系統 + 知識之間的連結

01:19

影片對第二大腦的定義是：把值得保留的資訊放進可靠的外部系統，以後需要時可以快速找到，也能看到知識之間的聯繫。

Obsidian 的定位不是單純記錄文字，而是把筆記、研究、文章和想法互相連起來，逐漸形成一個關聯的知識網路。

第二大腦
03

建立 Vault：Obsidian 知識庫就是本機資料夾

03:14

影片示範從官網下載 Obsidian，並說明它支援 iOS、Android、Windows、macOS 與 Linux。啟動後可以快速開始，也可以手動建立新 Vault。

講者更推薦手動建立 Vault，因為可以自行決定知識庫名稱與存放位置。影片也示範在 Obsidian 內建立文件夾與筆記後，本機資料夾裡也會同步出現相同內容。

Vault
04

Markdown 與本地優先：資料不被鎖在應用裡

04:48

Obsidian 裡的筆記以 Markdown 形式保存，因此即使離開 Obsidian，其他應用程式也能打開；影片也指出 Markdown 對 AI 和人類都相對容易讀懂。

這支影片強調 Obsidian 的一個核心理念：筆記屬於使用者自己，不會被鎖在單一應用內，使用者始終保有資料控制權。

本地優先
05

主畫面導覽：搜尋、書籤、白板、模板、命令面板與資料庫

05:23

影片依序介紹主畫面的常用按鍵：側邊欄收合、文件列表、搜尋、書籤，以及左側任務欄的快速切換、關係圖譜、新建白板、每日筆記、插入模板、命令面板與建立資料庫。

其中搜尋可查筆記、文件夾、標籤、行或章節；書籤可快速訪問常用內容並分組；白板可把文字、筆記與圖片拖到畫板上建立關係；資料庫可依條件篩選筆記。

介面功能
06

入門設定：先把附件集中到指定資料夾

08:12

影片建議到「設定 → 文件與連結」中，把附件的預設存放路徑改成指定附件資料夾。

這樣拖入圖片、PDF 或其他檔案時，Obsidian 會自動把附件放進指定資料夾，避免每次拖入圖片都讓整個知識庫變得凌亂。

設定
07

插件管理：核心插件可精簡，第三方插件需啟用社群市場

09:27

核心插件是 Obsidian 團隊預先提供的基本工具，有些預設開啟、有些預設關閉；影片建議關閉不需要的功能，減少介面雜亂。

第三方插件由開發者與使用者社群製作。若要安裝，需要關閉安全模式，再到社群插件市場瀏覽；也可以按下載量、更新時間、發布時間或名稱排序，安裝後還要按「啟用」。

插件
08

Markdown 基礎格式：標題、粗斜體、列表與任務勾選框

11:12

影片示範 Obsidian 的基本書寫格式：標題用 # 號，而且 # 後面要空一格；一個 # 是一級標題、兩個 # 是二級標題，依此類推。

粗體可用 Ctrl 或 Command + B，斜體可用 Ctrl 或 Command + I；數字加句點可建立有序列表，短橫線可建立項目符號，短橫線加空格與方括號可建立任務勾選框。

Markdown
09

雙向連結與反向連結：讓筆記變成知識網路

12:25

影片把雙括號連結描述為 Obsidian 的關鍵能力：遇到想深入了解的概念時，可以用雙括號連到既有筆記，也可以先建立尚不存在的筆記連結，之後再補內容。

反向連結會自動顯示目前筆記被哪些地方引用。隨著想法不斷互相連接，知識庫就不再只是傳統文件夾，而會變成不同想法之間的關係網路。

雙向連結
10

嵌入筆記、外部連結與關係圖譜：把內容彙總成可視化系統

14:32

如果想在一條筆記裡直接顯示另一條筆記內容，可以在雙括號前加驚嘆號來嵌入筆記；影片說這適合做概覽頁、總結或儀表板，也能避免在多個筆記中重複相同資訊。

關係圖譜則把筆記顯示為節點、連結顯示為線。當筆記越來越多，圖譜會形成圍繞特定主題的群組，成為思維的視覺地圖。

關係圖譜
11

文件夾 vs 連結：文件夾放位置，連結管關係

16:26

影片用城市比喻說明：文件夾像建築物，決定知識的存放位置；連結像道路，不移動建築物本身，而是展示不同地點之間的連接關係。

因此文件夾適合放附件、模板、歸檔項目、每日筆記、地圖或日曆等需要固定位置的內容；連結與反向連結才是整理知識關係的主要工具。

整理方法

文件夾像建築物，連結像道路；Obsidian 的重點不是把資料塞進更多資料夾，而是讓想法之間有路可走。
